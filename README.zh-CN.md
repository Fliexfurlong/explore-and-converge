# Explore and Converge：探索与收敛

[English](README.md)

一个按明确请求调用的思考技能：重新看问题、发散机制不同的方向、培育初步灵感，再根据需要形成选择、组合、条件分工、推进顺序或下一步验证。

**状态：** v1.2.0 英文公开试用版。尚未证明它能稳定改善真实决策。采用英文是为了方便阅读与传播，不代表已证明英文效果更好。

## 怎样使用

通过所用 agent 支持的安装方式，将本目录安装为 `explore-and-converge`，保留入口、参考、脚本及调用配置。不同宿主的发现与加载机制可能不同，未承诺所有平台通用。

手动选择技能，或在支持命名调用的环境中使用：

```text
$explore-and-converge 简单探索一个角度：我学习中断几天后，
总要重新翻很多笔记才能继续。只给一个值得先试的方向和原因，不要实施。
```

```text
$explore-and-converge 我写长文时资料越收越多，却迟迟开不了写。
分类和提醒已经试过。每周只能额外花半小时，不能买工具或找人。
探索机制不同的方向，比较成立条件，建议先试什么。本轮只讨论。
```

```text
$explore-and-converge 比较这三个方向，先看它们是互斥、互补还是前置关系。
不确定的成本明确保留，指出哪个事实会改变建议。
```

英文指令不要求用英文回答；输出遵循当前用户语言和指令。可只要发散、只发展一个灵感、只比较，也可指定方法和深度。

普通提问或讨论本技能不构成调用。助手主动建议使用时，需要先说明范围并获得批准。探索授权不自动包含实施。

## 轻量与边界

- 微型路径只做一个有价值的动作，足够就停。
- 标准探索按当前缺口读取参考，不强制完整工作坊。
- 先判断方向之间的关系，再决定是否需要排名。
- 区分事实、假设、用户偏好、真实硬约束和探索设定。
- Python 脚本按需使用，不要求联网或第三方库；它们支持抽样与计算，不验证建议是否真实有效。

`agents/openai.yaml` 保留 Codex 的显式调用设置；其他宿主是否识别该配置，需要分别确认。详见 [英文说明](README.md)、[定量工具接口](references/quantify.md) 和 [评估范围](docs/evaluation.md)。

现有小样本测试提供了一些正向信号，也出现过失分，尚不足以证明普遍优于直接提问、改善实际决策或节省 token。本轮英文翻译的检查与此前中文技能的行为结果应分开理解。
